# Internly - Internship Registration Assistant

A browser-based conversational assistant for internship registration across multiple career areas (task AI-SS-001).

## Features

- Guided natural-language registration flow for any internship area
- Intent handling for starting, confirming, editing, cancelling, help, and FAQs
- Validation for names, email addresses, and required answers
- Quick-reply suggestions and responsive mobile design
- Review screen before submission
- Local browser storage, generated registration ID, and JSON download

## Run locally

Open `dist/index.html` in a modern browser. No installation is required.

## Demonstration

1. Start the registration.
2. Enter a name and intentionally submit one invalid email to show validation.
3. Complete the education, interest, skills, and experience prompts.
4. Review the extracted details and confirm.
5. Download the generated registration summary.

## Privacy

The demo does not send personal information to a server. A completed registration is stored in the browser's local storage and can be downloaded as JSON.
